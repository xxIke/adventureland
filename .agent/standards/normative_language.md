# Normative Language

This project uses RFC 2119 / RFC 8174 key words for requirement levels.

| Keyword | Meaning |
|---------|---------|
| **MUST** / **MUST NOT** | Absolute requirement. If you cannot satisfy it, stop and document the blocker. |
| **SHOULD** / **SHOULD NOT** | Strong default. Deviations require documented rationale. |
| **MAY** | Optional. Apply with judgment based on context. |

When these terms appear in uppercase in standards, mandates, rules, and checklists, they carry the normative meaning defined above.
